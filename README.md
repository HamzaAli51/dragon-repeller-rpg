# Dragon Repeller

A simple browser-based RPG built with HTML, CSS, and vanilla JavaScript (no frameworks/libraries).

## Features
- Turn-based combat with attack/dodge/run mechanics
- Weapon shop with buy/sell system
- Gold and XP progression
- Random weapon-break chance during fights
- Hidden easter egg mini-game (number guessing)
- Win/lose states with replay option

## How to play
Open `index.html` in your browser and use the buttons to navigate the town, buy gear, fight monsters, and try to defeat the dragon.
